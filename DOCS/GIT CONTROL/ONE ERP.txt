* Modular Architecture
* API-First
* Feature Flag Based
* Role-Based Security
* Field-Level Permissions
* Approval Workflow

* Global Tax Engine
* Multi-Company
* Multi-Branch
* Multi-Currency
* Multi-Language
* World-Class Scalable Architecture

## Final Goal

Build **ONE ERP** as a **single global SaaS platform** where:

* **Billing customers** use core modules (Purchase, Sales, POS, Inventory).
* **ERP customers** enable additional modules (Finance, CRM, HRMS, Manufacturing, etc.).
* Both editions share the same codebase, database design, and master data, with functionality controlled by subscriptions, feature flags, and permissions. This minimizes maintenance, simplifies upgrades, and allows customers to grow without migrating to a different system.



For a **world-class ONE ERP**, I recommend these **System Master Tables**.

## Taxes

```sql
CREATE TABLE Taxes
(
    Id              INT IDENTITY(1,1) PRIMARY KEY,
    TaxCode         NVARCHAR(30) NOT NULL UNIQUE,
    TaxName         NVARCHAR(100) NOT NULL,
    CountryId       INT NOT NULL,
    StateId         INT NULL,
    TaxRate         DECIMAL(8,3) NOT NULL,
    IsRecoverable   BIT NOT NULL DEFAULT 1,
    EffectiveFrom   DATE NOT NULL,
    EffectiveTo     DATE NULL,
    IsActive        BIT NOT NULL DEFAULT 1,
    CreatedDate     DATETIME2 NOT NULL DEFAULT GETDATE()
);
```

## TaxGroups

```sql
CREATE TABLE TaxGroups
(
    Id              INT IDENTITY(1,1) PRIMARY KEY,
    GroupCode       NVARCHAR(30) UNIQUE,
    GroupName       NVARCHAR(100),
    Description     NVARCHAR(250),
    IsDefault       BIT DEFAULT 0,
    IsActive        BIT DEFAULT 1,
```

## TaxGroupDetails

```sql
CREATE TABLE TaxGroupDetails
(
    Id              INT IDENTITY PRIMARY KEY,
    TaxGroupId      INT NOT NULL,
    TaxId           INT NOT NULL,
    SequenceNo      INT NOT NULL,

    FOREIGN KEY(TaxGroupId) REFERENCES TaxGroups(Id),
    FOREIGN KEY(TaxId) REFERENCES Taxes(Id)
);
```

### Seed Data

